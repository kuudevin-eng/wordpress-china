# ERPNext 中国版 WebUI（Demo）

这是一个面向中国企业使用场景的 ERPNext WebUI 原型，重点强调：

- 中文本地化与中国业务语义（税务、发票、供应链、排产等）
- 多 Agent 协作面板（可按任务自动分派）
- 轻量前端实现，便于后续接入 ERPNext/Frappe API

## Agent 分工策略

| Agent | 核心职责 | 触发关键词 |
|---|---|---|
| 财税合规 Agent | 增值税申报、发票核验、总账异常检查 | 税、发票、申报、合规 |
| 销售增长 Agent | 线索评分、报价优化、回款风险预测 | 销售、报价、客户、回款 |
| 采购优化 Agent | 供应商比价、缺料预警、安全库存建议 | 采购、缺料、库存、供应商 |
| 生产排产 Agent | 工单拆解、班组排产、瓶颈识别 | 排产、工单、生产、班组 |
| 客服体验 Agent | 售后工单分类、情绪分析、满意度提升 | 默认兜底 |

## 快速运行

直接打开 `webui/index.html`，或者使用任意静态服务：

```bash
python3 -m http.server 8000
```

然后访问：`http://localhost:8000/webui/`

## 下一步接入建议

1. 使用 Frappe/ERPNext API 替换当前 `app.js` 中模拟数据。
2. 通过统一网关引入中国常见生态（企业微信、钉钉、电子发票平台）。
3. 将分派逻辑升级为可学习策略（按 SLA、成功率、业务优先级动态调度）。
